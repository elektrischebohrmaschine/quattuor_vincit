# QUATTUOR_VINICI

Dieses Projekt ist eine Umsetzung des Spiels Vier Gewinnt, die auf einer Client-Server-Architektur mit TCP basiert. Der Server ist dafür ausgelegt, mehrere Clients gleichzeitig zu bedienen und mehrere Spiele parallel zu verwalten.

## Spielbeschreibung:
Das Spiel wird im online Modus gespielt. Dadurch ist es möglich, gegen andere registrierte Spieler zu spielen (Freundesliste).

Als Erweiterung wurden ein Level-System sowie ein Highscore-System implementiert. Diese dienen dazu, den Spielfortschritt der Nutzer darzustellen und Spielergebnisse miteinander zu vergleichen.\
Das Spiel wird nicht lokal installiert, sondern über eine bestehende Verbindung zwischen Client und Server genutzt.

## Features:
- TCP-basierte Kommunikation zwischen Client und Server
- Verwaltung mehrerer paralleler Spielsessions
- Möglichkeit zur Registrierung/ Login
- Online-Spiele mit Spielern aus der Freundesliste
- automatische Synchornisation möglich
- Offline-Spielmodus
- Level-System
- Highscore-System
